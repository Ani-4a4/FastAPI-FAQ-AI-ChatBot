# FastAPI FAQ AI ChatBot

An AI-powered FAQ chatbot built with **FastAPI** and Google's **Gemini
API**. The application answers customer questions using business
information stored locally in JSON, helping users get concise responses
without needing to search through FAQ content manually.

## Features

-   **AI-generated answers** using Google's Gemini model.
-   **Business-specific responses** selected using a business ID.
-   **Grounded FAQ responses**: the prompt instructs the model to answer
    using the supplied business information and to admit when the
    information does not contain an answer.
-   **FastAPI endpoint** for submitting questions.
-   **Static frontend** served by FastAPI.
-   **Environment-based API key configuration** to keep credentials out
    of source code.

## Tech Stack

-   Python
-   FastAPI
-   Google GenAI SDK
-   Pydantic
-   `python-dotenv`
-   HTML, CSS, and JavaScript for the static frontend

## Requirements

-   Python 3.10 or a compatible version supported by the dependencies
-   A Google Gemini API key
-   Internet access for API requests

## Setup

### 1. Clone the repository

``` bash
git clone https://github.com/Ani-4a4/FastAPI-FAQ-AI-ChatBot.git
cd FastAPI-FAQ-AI-ChatBot
```

### 2. Create a virtual environment

**Windows (PowerShell):**

``` powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

``` bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

``` bash
python -m pip install -r requirements.txt
```

### 4. Configure the API key

Create a `.env` file in the project root (you can use `.env.example` as
a reference) and add:

``` env
GEMINI_API_KEY=your_gemini_api_key
```

Replace the placeholder with your own key. Do not commit `.env` or
expose your API key publicly.

### 5. Start the server

``` bash
uvicorn bot:app --reload
```

Open the local address shown in the terminal. The static frontend is
served by the application.

## API Usage

The chatbot exposes a `POST /ask` endpoint.

### Example request

``` json
{
  "message": "What are your opening hours?",
  "business_id": "example_business"
}
```

Replace `example_business` with a valid key from `data/businesses.json`.

### Example response

``` json
{
  "response": "The business's answer will be returned here."
}
```

The response is generated by Gemini based on the selected business's
information. If the business ID is unknown, the API returns a `404`
error. If the AI request fails, it returns a `500` error.

## How It Works

1.  The frontend submits a question and a business ID to `/ask`.
2.  FastAPI validates the request using a Pydantic model.
3.  The application loads the business data from `data/businesses.json`.
4.  It selects the requested business and builds a prompt from that
    business's information.
5.  Gemini generates a concise answer.
6.  The API returns the answer as JSON.

## Customising the FAQ Knowledge Base

Edit `data/businesses.json` to add or update business entries. Each
entry should follow the structure expected by `bot.py`, including a
business `name` and `info` field. The `business_id` sent to the API must
match a key in the JSON file.

## Notes and Limitations

-   The application requires a working Gemini API key and internet
    access.
-   Answers depend on the completeness and accuracy of the business
    information in the JSON file.
-   The prompt encourages the model not to guess when information is
    missing, but AI-generated answers should still be reviewed for
    accuracy.
-   For production use, configure CORS for trusted origins rather than
    allowing every origin, and consider rate limiting and
    authentication.
